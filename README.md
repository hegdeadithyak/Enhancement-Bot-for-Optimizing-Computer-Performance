# Efficient Temporary File Management 

Empowering Users to Enhance System Performance

Temporary files pile up in systems over time, eating up space and slowing performance. This application automates the detection, management, and removal of unnecessary temp files, helping users keep their machines fast, light, and efficient.

✨ Features

🔍 Smart Scan – Detect unused and temporary files.

🗑 One-Click Cleanup – Free up disk space instantly.

⚡ Performance Boost – Reduce clutter for smoother system operation.

⚙️ Custom Rules – Allow users to choose what to keep or remove.

📊 Reports & Insights – Show storage usage before and after cleanup.
